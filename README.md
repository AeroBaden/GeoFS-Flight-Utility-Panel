# GeoFS-Flight-Utility-Panel

All-in-one panel for GeoFS: Flight Timer, Fuel Calculator, Logbook (TXT), and Route Time Calculator.

## Installation

1. Install [Tampermonkey](https://www.tampermonkey.net/) or [Greasemonkey](https://www.greasespot.net/).
2. Click on `geofs-flight-utility-panel.user.js` file in this repository.
3. Tampermonkey will prompt you to install the script. Accept it.
4. Open GeoFS and enjoy the utility panel.

## There are inaccuracies in the route calculator. I'm working on more features coming in the future, like a fuel calculator and weather data.
